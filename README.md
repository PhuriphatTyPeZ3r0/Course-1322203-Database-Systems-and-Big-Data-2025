## 🎯 โครงงานประจำรายวิชา (Course Projects)

### 🏆 Student Registration System (Register-System)
- **บทบาทและหน้าที่:** ระบบลงทะเบียนนักศึกษาและจัดการข้อมูลผู้เรียน เชื่อมต่อฐานข้อมูลเชิงสัมพันธ์แบบเรียลไทม์
- **เทคโนโลยี:** Java, Java Swing (NetBeans GUI), MySQL Connector/J 9.5.0, SQL Queries
- **ฟีเจอร์เด่น:**
  - เพิ่ม แก้ไข ค้นหา และลบข้อมูลผู้ลงทะเบียน (CRUD Operations)
  - Data Validation ป้องกันความซ้ำซ้อนของรหัสนักศึกษา
  - Transaction Management และจัดการ Connection Pool อย่างปลอดภัย
- **โฟลเดอร์โครงงาน:** [Register-System](03_Projects/Register-System/)

- [x] ออกแบบ Entity-Relationship Diagram (ERD) และแปลงเป็น Relational Schema ได้อย่างถูกต้อง
- [x] ดำเนินการ Normalization เพื่อลดความซ้ำซ้อนของข้อมูลและคงความถูกต้อง (Data Integrity)
